# Bengaluru House Price Prediction 🏡

A Machine Learning web application to predict residential real estate prices in Bengaluru based on location, square footage, number of bedrooms (BHK), and bathrooms.

## Features
- **Accurate Predictions**: Powered by a trained Scikit-learn Linear Regression model.
- **Interactive UI**: Responsive web interface with location auto-complete and instant price estimation.
- **REST API**: Supports both web forms and JSON POST requests.

## Tech Stack
- **Backend**: Python, Flask, Scikit-learn, Pandas, NumPy
- **Frontend**: HTML5, CSS3, JavaScript
- **Server**: Gunicorn

## Run Locally
1. Clone the repository or download the project files.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Open [http://127.0.0.1:5000/](http://127.0.0.1:5000/) in your web browser.
